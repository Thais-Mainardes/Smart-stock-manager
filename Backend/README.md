# Backend do Smart Stock Manager

## Objetivo

O backend será responsável pelas regras de negócio do Smart Stock Manager e pela comunicação entre o frontend, banco de dados e módulo de Inteligência Artificial.

## Tecnologia

- C#
- .NET
- API REST

## Principais responsabilidades

- Gerenciamento de produtos.
- Gerenciamento de categorias.
- Gerenciamento de fornecedores.
- Controle de entradas e saídas.
- Gerenciamento de usuários.
- Comunicação com o banco de dados.
- Disponibilização de dados para o módulo de Inteligência Artificial.

## Estrutura planejada

O backend será organizado seguindo uma arquitetura que facilite a manutenção, os testes e a evolução do sistema.

A implementação será iniciada após a configuração do ambiente .NET.
