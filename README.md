# Smart Stock Manager

Sistema de gerenciamento e análise de estoque desenvolvido para praticar e demonstrar conhecimento em desenvolvimento de software, banco de dados, APIs, análise de dados e inteligência artificial.

# Objetivo

O projeto tem como objetico desenvolver uma solução para controle de estoque, permitindo o gerenciamento de produtos, fornecedores e movimentações, além da geração de indicadores e análise para auxiliar na tomada de decisões.

# Tecnologias

C#
.NET
ASP.NET Core
SQL Server
Entity Framework Core
HTML
CSS
JaVaScript
Git e GitHub

# Funcionalidades
Cadastro de produtos
Cadastro de fornecedores
Controle de entrada e saída 
Consulta de estoque
Alertas de estoque baixo
Dashboard de indicadores
Históricos de movimentações
Autenticação de usuários
Análise utilizando inteligência artificial
